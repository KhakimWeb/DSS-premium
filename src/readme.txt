1. Критические стили подключаются напрямую в шапку
2. Некритические стили подключаются с помощью JS.  (src/assets/js/components/styles.js)
3. В папке partials находятся повторябщиеся блоки.
4. Перед переносом на WP:
    - Поменять путь для mailer в JS файле
    - Поменять путь для подключения некритических стилей. Исправить на 'wp-content/themes/theme-name/'
